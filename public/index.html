START / 使用指引

自己的地图，大家的美食

  1. 上传内容：登录后点“分享”，填写店名、分类、地址、GCJ-02 坐标并授权。图片、优缺点、菜单价格均选填；人工审核后公开。
  2. 删除自己的内容：打开“我的投稿”→“删除”，确认后从公共服务撤回。公开 GitHub PR、历史记录和他人下载副本不能自动抹除；可通过反馈请求管理员处理。
  3. 反馈：顶部“反馈”支持手动 GitHub Issue 或登录后自动反馈，请先遮挡隐私。
  4. 查看他人内容：通过地点列表搜索或分类筛选，点击卡片或地图标记查看详情；未配置地图也能浏览列表。
  5. 设置 API：“设置”填写自己申请的 JSAPI Key 和配套安全码。详细 README 教程可在下方打开。个人 API 大量使用可能需付费，Key 仅存本机，源码开放审查。
  6. 评分评价：地点详情中选择 1～5 分，可选文字。服务端按北京时间限制同一 IP 或随机设备标识每日对同一地点一次，可评价多个地点。只存每日加盐哈希，不采集硬件指纹；共享网络可能误限，清除设备数据与更换网络可绕过，不能保证绝对刷票。

以后可从顶部“使用指引”再次打开。
