# 自己的高德 API，大家的美食地图

适用：桂电美食分享 Web 与 Android。文档更新：2026-11-01。高德控制台的名称、免费额度、计费和认证要求可能调整，请以你账户当前显示的规则为准。

## 1. 为什么需要自行申请

高德个人 API 大量使用、超出免费额度、使用收费服务或涉及商业授权时，需要按高德规则缴费或购买相应服务。因此，请你自己申请 API，管理自己的调用量和费用。本项目不提供让所有用户共用的个人 Key，也不会承诺无限免费。

个人 API 不会上传到本项目服务器、GitHub 仓库、投稿记录或地点导出文件。地图需要联网认证：Key 以及相应安全信息会由你的浏览器或手机直接发送给高德。这里的“不上传”指不交给本项目保存，不代表高德地图可以离线免认证使用。

项目代码已经开源，欢迎审查：[Android 与投稿流程源码](https://github.com/zxymiku/guet-food-share)、[Web 与服务器源码](https://github.com/zxymiku/guet-food-share-web)。不要将个人 API 粘贴到 GitHub Issue、PR、反馈文字或截图。

## 2. 先选对平台和填写位置

| 使用场景 | 高德控制台的平台类型 | 需要填写 | 在本项目的填写位置 |
| --- | --- | --- | --- |
| 浏览器查看地图、选点、自动填写地址 | Web 端（JSAPI） | Key 和配套 securityJsCode | 网页顶部“设置”（地图 API） |
| Android 查看地图与选点 | Android 平台 | Android Key | 应用顶部“设置”（地图 API） |
| Android 自动填写地址（可选） | Web 服务 | Web 服务 Key | Android“地图 API”中的可选栏 |

三种 Key 不通用。Web 端不需要 Android Key，也不需要填写 Web 服务 Key。Android 不需要 securityJsCode；不填写可选 Web 服务 Key 时，仍能显示地图、选点、定位和手工填写地址。

## 3. 注册高德开放平台并创建应用

1. 打开[高德开放平台](https://lbs.amap.com/)，点击注册或登录。也可以直接打开[开发者控制台](https://console.amap.com/)。
2. 按页面提示完成手机号验证、开发者资料与必要的实名认证。个人使用选择适合自己的个人开发者身份；经营或商用场景请先核对授权要求。
3. 在控制台查找“应用管理”→“我的应用”。首次进入没有应用是正常情况。
4. 点击“创建新应用”，名称可以填“我的桂电美食地图”，应用类型按实际用途选择。一个应用下面可以有不同平台的 Key。
5. 在该应用下点击“添加 Key”，填写能区分平台的名称，如“美食地图-Web”或“美食地图-Android”。
6. 选择平台类型，再按下面对应章节完成配置。不要因为已有一个 Key 就将它复制到所有平台。

本教程没有真实 Key，也不代你注册账户、进行认证、开通套餐或支付费用。

## 4. Web：申请 JSAPI Key 和安全密钥

1. 添加 Key 时，服务平台选择“Web 端（JSAPI）”。“Web 服务”是另一种类型，不能替代。
2. 根据当前控制台要求设置域名白名单。使用正式网站时填 `food.zxymiku.top`。若界面要求仅域名，不加 `https://`、路径或斜杠；按该字段的提示填写，不使用任意域名通配符。
3. 如果你部署了自己的 Web 副本，应填写你实际访问的域名。`localhost`、`127.0.0.1`、另一个子域名或自定义端口可能不等同于生产域名，开发时应单独申请测试 Key，并依高德要求设置白名单。
4. 保存后，在 Key 列表或详情找到“Key”以及“安全密钥”（`securityJsCode`）。两个字段通常都是 32 位十六进制字符串，但它们不是同一个值。安全密钥必须与这个 JSAPI Key 配套。
5. 返回桂电美食分享网页，点击顶部“设置”（地图 API）。没有地图时也可以点击地图区域的“填写自己的高德 API”。
6. 将 JSAPI Key 粘贴到第一栏，将同一个 Key 的 `securityJsCode` 粘贴到第二栏。页面使用遮蔽输入框，避免旁人直接看到。
7. 默认勾选“在此浏览器长期记住”。点击“保存并加载地图”后页面重载，地图会自动加载，之后再次访问、关闭并重启浏览器、退出本项目账号，都不需要重新填写。
8. 等待地图显示，再点击任一公开地点。地图和标记依赖你的 API；地点文字、坐标和图片引用来自共享公开记录。

### Web 的保存方式与边界

默认长期保存使用浏览器本地存储 `localStorage`，没有应用设定的自动过期时间。它不是云端账号同步：换设备、换浏览器、换网站域名、无痕窗口、手动清理网站数据或浏览器自动清理后，需要重新填写。浏览器禁止存储时会显示错误，不会声称保存成功。

在公共设备上取消勾选，改用“仅当前标签页”模式。该模式使用 `sessionStorage`，一般关闭标签页后清除；浏览器恢复会话功能可能恢复标签页数据，因此离开公共设备前仍请主动清除。

凭据以本地文本保存。浏览器扩展、同源页面脚本及有设备访问权的人可能读取；本项目不会把它们写入 Cookie、服务器账户或公开数据。调用高德 JS SDK 时，Key 和安全码本来就必须供浏览器使用，不能把前端存储当作保险库。

高德官方同时介绍了服务端安全代理方案。本项目采用个人凭据在客户端直接接入，避免项目服务器收集每位用户的密钥；这不等同于服务端代理的保密性。请配置域名限制、关注额度，若你的使用场景必须隐藏安全码，应部署由自己控制的代理并按官方规范接入，不要把密钥交给公共项目服务器。[高德安全密钥说明](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)。

### 修改或清除 Web API

打开“地图 API”，直接替换两个字段并保存。更换 Key 时必须同时核对配套安全码。页面重载会重新创建高德 SDK 实例，避免继续使用旧 Key。保存前请处理未提交的投稿表单。

点击“清除本机 API 并关闭地图”会删除长期和当前标签页两种存储，并重载页面。其他已打开的本站标签页也会响应长期设置变化而重载；公共设备操作结束后请关闭所有相关标签页。清除地图 API 不会删除公开地点，也不会退出登录。

## 5. Android：申请与你的安装包匹配的 Key

1. 安装本项目 Android 应用，打开顶部“设置”（地图 API）。首次打开无需登录、无需填写 Key，也能进入此页面和离线教程。
2. 找到“包名”与“当前签名 SHA-1”。使用页面提供的“复制包名”“复制当前 SHA-1”，不要手抄。它们由手机读取当前安装包计算得出。
3. 高德控制台 → 我的应用 → 添加 Key → 服务平台选择“Android 平台”。
4. 包名填 `com.guet.foodshare`。自编译时若更改了包名，必须以安装后设置页显示的包名为准。
5. 在对应的发布版/调试版 SHA-1 字段填入当前安装版本的签名指纹。正式 Release 用发布证书 SHA-1；本地 debug 构建使用调试证书 SHA-1。不要填 SHA-256，也不要使用另一个开发者的 debug 指纹。
6. 官方正式安装包当前公开的发布证书 SHA-1 如下；如以后签名信息更新，优先使用应用内实际显示的值。

```text
包名：com.guet.foodshare
正式证书 SHA-1：15:12:5E:C6:61:AA:F9:D6:A2:34:D7:49:67:E0:B8:E9:D9:C5:69:68
```

7. 保存得到 Android Key，返回应用，将其粘贴到“Android 平台 Key”栏。
8. 阅读高德服务说明和隐私政策，勾选同意后点击“保存并启用地图”。不授予系统定位权限也能浏览地图和手动选点；只有主动点击定位时才请求系统权限。
9. 若底图不显示，检查 Key 平台、包名、当前证书 SHA-1、控制台服务权限、网络与额度。修改配置后重新保存；仍不生效可完全关闭并重新打开应用，等待控制台配置传播后再试。

不需要修改源码、重新构建 APK 或让管理员把你的 Key 加到 GitHub Secret。应用使用 Android 系统密钥库对凭据加密，保存在应用私有目录，禁用系统备份；退出项目账号不清除地图 API。卸载应用、清除应用数据或密钥库失效后需重新填写。设置页禁止普通系统截图和录屏，仍请自行保护设备。

[高德 Android Key 申请说明](https://lbs.amap.com/api/android-sdk/guide/create-project/get-key) · [高德隐私政策](https://lbs.amap.com/pages/privacy/)

## 6. Android 可选：自动填写门店地址

1. 在同一应用下另外添加 Key，服务平台选择“Web 服务”。命名如“美食地图-地址解析”。
2. 按当前控制台要求启用地理编码/逆地理编码服务，核对该服务的每日额度和调用频率。
3. 返回 Android → 地图 API → “Web 服务 Key（可选）”，粘贴该 Key，与 Android Key 一起保存。
4. 登录项目后进入分享表单，选择“在地图上选点”或“定位并自动填写地址”。坐标先写入表单，再由手机直接请求高德逆地理编码接口。解析得到地址，并可能建议附近 80 米以内的店名。
5. 必须核对实际店名、门牌和门店位置。附近 POI 可能是隔壁店；设备定位可能位于宿舍或道路，并不等于门店位置。确认内容后才提交。

该可选功能是手机直连高德，不经过项目 Worker。不要填写项目服务器的 IP 白名单：请求来自你的手机网络出口，移动网络或 Wi-Fi 切换会改变 IP。若当前高德账户政策要求固定 IP、安全签名或服务端使用，或你不愿在手机保留 Web 服务 Key，请留空并手动填写地址。本应用没有让你填写私钥或关闭账户安全限制的要求，也没有实现服务端签名代理。

Web 端的地址解析使用自己的 JSAPI Key 与 Geocoder 插件，不使用本栏。

## 7. 额度、收费和异常排查

控制台查找“用量/配额/流量分析”“服务管理”“费用/订单/资源包”等栏目，按应用、Key 和具体服务检查。不同 SDK 和接口的免费次数、QPS、计量单位及商业许可可能不同；个人认证不代表全部服务永久免费。开发者认证费用、调用超额费用、付费能力与商业授权也不是一回事。

大量使用或选择收费能力前，先查看[高德服务与权益入口](https://lbs.amap.com/upgrade)和账户内的当前价格说明，确认是否需购买资源包、升级权益、充值或单独取得许可。若控制台支持限额、告警或停用开关，按自己的预算设置。配额耗尽可能限流或停止服务，并不一定自动扣费；具体按账户已开通的合同与计费方式执行。本项目不会代你付费或自动购买。

| 现象 | 优先检查 |
| --- | --- |
| 32 位格式错误 | 是否复制完整、有空格、把应用名称当成 Key、Key 与安全码是否对调 |
| Web 白屏或 INVALID_USER_KEY | 是否选了 Web 端（JSAPI）、Key 是否被禁用、网络能否访问高德 |
| INVALID_USER_SCODE | JSAPI Key 与 securityJsCode 是否配套、是否刚更换配置 |
| INVALID_USER_DOMAIN | 实际访问域名是否被允许，localhost 与生产环境是否混用 |
| Android 底图不显示 | Android Key、包名和当前安装证书 SHA-1 是否三者对应 |
| USERKEY_PLAT_NOMATCH | Key 平台与当前 API 是否匹配；错误码名称以高德响应为准 |
| 地址解析失败但地图正常 | Android 可选 Web 服务 Key、接口权限、IP 限制或对应额度 |
| CUQPS_HAS_EXCEEDED_THE_LIMIT / 配额耗尽 | 降低频率，查看当前服务用量和套餐；不要通过共享他人 Key 绕过限制 |
| 地图正常但没有门店 | 是否有已审核公开的数据、是否设置了搜索/分类筛选、网络能否读取公开列表 |
| 下次访问又要填 | 是否关闭了长期保存、清理了站点数据、换了域名/浏览器、使用了无痕模式 |
| 点位整体偏移 | 是否误把 WGS-84 或 BD-09 当作 GCJ-02；不要重复转换已有高德坐标 |

Key 误公开时，去高德控制台撤销/重置对应凭据，再在本机重新填写。报告问题时描述平台、时间、现象和错误码即可，遮挡 Key、安全码、账号和私人位置。

## 8. 其他人的 API 为什么也能显示你的标记

地图 API 是加载底图和使用高德服务的凭据，地点数据是独立的公开记录。A 用户用自己的 Key 标记门店，提交的内容包括店名、分类、地址、推荐理由、前往方法、GCJ-02 经度纬度、图片/视频引用和公开授权；提交 ID、创建时间和发布时间由系统记录。A 的 Key 不写入这些数据。

投稿经人工审核公开后，B 用户无论在 Web 还是 Android 上填写自己的 Key，都读取同一个公开地点列表，并在 B 的地图上按保存的坐标绘制标记。无需 A 的 Key，A 撤销或更换自己的 Key 也不会移除已公开的标记。未提交或待审核点位只对相应流程可见，不会因为点过地图就自动公开。

应用自动读取所有分页，不再仅显示最近 500 条。新地点公开后，Web 重新加载页面、Android“更多”→“刷新公开地点”即可获取。

### 保存与读取完整档案

Web 点击“导出全部公开地点”，Android 点击“更多”→“导出全部公开地点”，可以保存 JSON。导出含所有公开地点及媒体引用、坐标系、版本和时间；不含任何人的地图 API、登录凭据或待审核草稿。

媒体以引用形式记录，JSON 不嵌入照片/视频二进制，也不包含解密密钥。读取者用 `mediaBaseUrl` 加相对路径访问原站已公开媒体；将 JSON 离线归档时如需长期保存媒体，应另行下载有权使用的公开媒体。图片/视频服务的可用性仍依赖原站和媒体存储，不能把 JSON 当成全部媒体文件的离线备份。

开发者可读取 `/api/places?limit=200`，持续使用返回的 `nextCursor` 请求后续页，直到为 `null`。每条记录中的 `location.lng` 是经度，`location.lat` 是纬度，`location.crs` 固定为 `GCJ-02`。高德 JS Marker 使用 `[经度, 纬度]`，Android `LatLng` 使用 `(纬度, 经度)`，不要颠倒，也不要再做一次 GPS 转换。读取导出文件时使用 `archive.places`，媒体地址用 `new URL(path, archive.mediaBaseUrl)` 解析。详情字段应作为文本渲染，不作为 HTML 或可执行脚本。

开放数据让大家共享标记，个人 API 只负责各自的地图访问。申请完成后回到“地图 API”填写即可。


## 9. 新版本字段、评分和撤回

分类配置位于 `public/categories.json`，默认后街、前街、餐厅，餐厅有多种子分类。上传优点、缺点、菜单价格均选填。地图点与评价使用稳定地点 ID 关联；详情读取公开评分和评价。个人 Key 不进入上传白名单。

更多/我的投稿可撤回自己在当前身份下上传的内容。共享密码也按设备区分身份；丢失设备身份或清理登录存储后不能证明旧投稿所有权，需联系管理员。撤回会移除公共服务记录，公开 GitHub 历史和他人副本不能自动消除。

同一 IP 或随机设备标识按北京时间每日对同一地点限评一次，可以评价多个不同地点。只存每日 HMAC，不收集硬件指纹、不保存原始 IP；摘要随评价保留用于去重与审计。共享网络可能误限；清数据并更换网络可能绕过，后续可接 Turnstile 或实名账号信誉机制。评分文字公开，请勿填写私人信息。

官方说明核对日期：2026-11-01。高德当前控制台用词、实名认证要求、服务权限和计费以账户内规则为准；示例中的 YOUR_JSAPI_KEY、YOUR_SECURITY_JS_CODE、YOUR_ANDROID_KEY 均为占位符，不能直接使用。


## 10. 收藏、纠错与隐私边界

- “筛选与排序”可选择本机收藏、想去、吃过、子分类、评分、人均预算和距离。“今天吃什么”只从当前筛选随机选择，多于一个候选时避免连续重复。
- 收藏与足迹只保存地点 ID 和主动选择，Web/Android 不自动互传；定位仅驻留内存。公开地点文本可缓存，离线时会标注过期风险，地图与媒体不承诺离线可用。清理浏览器数据或卸载会丢失本机清单，设置可独立清除缓存/清单。
- 人均价格、营业时间和饮食标签均由用户提供，不代表实时营业或过敏原安全保证，请直接与门店核实。
- 分享链接只包含公开地点 ID，不含地图 Key、账号或私人清单。
- 评价保存内部账号 ID 以验证本人撤回权限，不在公共接口暴露。本人可撤回新版本评价，撤回不会重置同一账号/IP/设备当日额度；旧版本无作者信息的评价需举报审核处理。
- 地点和评价都可纠错/举报，每个账号每天最多 20 条，同一内容每天一次；举报者身份不公开。审核员可处理、隐藏内容、恢复地点；隐藏不删除原审核历史，所有审核操作留内部审计记录。
